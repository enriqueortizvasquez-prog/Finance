# Finance

App personal de finanzas (APK, datos 100% locales).

## Prototipos de diseño

`prototipos/index.html` — prototipo interactivo con 5 direcciones de diseño oscuro/orgánico:
Obsidiana Líquida, Tinta y Humo, Onda/Frecuencia, Arcilla Oscura y Gradiente Vivo.

Ábrelo directamente en el navegador (o `python3 -m http.server -d prototipos`).
Funciones: agregar/editar/eliminar movimientos, categorías, presupuestos por categoría,
navegación por meses, búsqueda/filtros, exportar/importar respaldo JSON.
